# Portfolio
My own portfolio website, made from scratch using HTML, CSS and Javascript for any functionality.

## Features
- Runtime DOM elements and HTML is injected to build up the page structure to avoid the need to copy around dynamic or complex elements between files.
- Expandable images
- In-page navigation
- Mostly mobile supported
- Code previews driven by Prism
- Tooltips to show extra information
- Content switchers
- And more that I am probably forgetting

## Purpose
To show my work in game-dev for other people to see ofcourse! 
Could also serve as a template or inspiration for other people with some or limited experience in web-development, as the techniques I've used do not require experience or knowledge in servers or other languages.
