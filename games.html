My learning

The project was an amazing opportunity for working in 3D, where I learned to work with developing AI, designing and creating the exciting player combat and create the overall systems required for UI and level design to be created by my team with ease. Working with an engine like Unreal that's designed to invite other designers like graphics and level design taught me the importance of designing and creating with the team in mind, so that I can create systems and tools that are intuitive and usable for others too.
